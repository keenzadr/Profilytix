# Profilytix: экспериментальный макет интерфейса

Обновление: пользователь согласовал направление с переключателем темы внизу слева
и узкой панелью. Изменения внесены в макет и рабочее приложение. Текущие снимки
рабочего окна с настоящим анализом синтетических данных — `working_previews/`.

Это отдельный, одноразовый прототип для согласования визуального направления.
Он не импортирует рабочее приложение, не заменяет его интерфейс и не меняет данные.

## Запуск и снимки

```powershell
python prototypes/ui_preview.py
python prototypes/ui_preview.py --render-dir prototypes/previews
python prototypes/ui_preview.py --render-dir prototypes/previews/compact --size 1000x700
python prototypes/ui_preview.py --render-dir prototypes/previews/scale125 --scale 1.25
python prototypes/ui_preview.py --render-dir prototypes/previews/scale150 --scale 1.5
python prototypes/ui_preview.py --render-dir prototypes/previews/collapsed --collapsed
python prototypes/render_working_ui.py --render-dir prototypes/working_previews
```

Снимки создаются непосредственно средствами Qt: пять светлых экранов и тёмный
обзор. `render_manifest.json` содержит логический размер окна, реальный DPR,
геометрию области просмотра и максимумы прокрутки каждого экрана. В режиме снимков
используется Qt offscreen; на Windows в нём явно регистрируются установленные
шрифты Segoe UI, поскольку платформа offscreen сама их не обнаруживает.

## Выбранное направление

- Нативные Qt Widgets и обычная системная рамка Windows: заголовок, изменение
  размера, сворачивание и разворачивание остаются у ОС.
- Статическая боковая навигация по пяти согласованным разделам. Общий образ
  боковой панели вдохновлён PyOneDark; его исходные виджеты и код здесь не используются.
- Светлые серо-голубые поверхности, белые карточки и спокойный бирюзовый акцент.
  Финансовая структура, компактные фильтры и таблицы ориентируются на Actual Budget;
  его frontend-код не переносится.
- Тёмная тема использует те же отступы, смысловые цвета и контрастные поверхности.
- Матplotlib встроен как настоящий `FigureCanvasQTAgg`, предпросмотр — настоящий
  `QTableWidget`. Текст и пиктограммы рисуются в Qt, это не картинка интерфейса.
- Экран 1280×850 показывает каждый раздел без внешней прокрутки. При 1000×700
  сохраняется ширина содержимого, а длинные страницы получают вертикальную прокрутку.
  Таблица операций имеет собственную вертикальную прокрутку до 100 строк.

## Что действительно работает

Навигация, светлая/тёмная тема, выделение строк и прокрутка таблиц, выбор метода
с изменением пояснения. Выбор IQR / Z-score / Isolation Forest меняет только справку;
фиксированный демонстрационный сигнал не выдаётся за пересчитанный результат.

Загрузка файлов, фильтры, соответствие столбцов, редактор правил и экспорт отключены.
Будущий редактор правил прямо обозначен как предложение для следующего этапа.
В верхней панели всегда виден бейдж «Макет · демонстрационные данные».

## Компромиссы и границы проверки

Системная рамка надёжнее экспериментальной безрамочной оболочки, но её цвет
определяет Windows. Скриншоты `QWidget.grab()` показывают клиентскую область и не
подтверждают работу системной рамки или реального изменения DPI между мониторами.
Параметр `--scale` проверяет отрисовку Qt при заданном коэффициенте; ручная проверка
Windows всё ещё нужна для системного масштабирования, максимизации и переноса окна.

Сам одноразовый прототип остаётся в `prototypes/`. Его фиксированные сигналы
не используются в приложении. По следующему поручению пользователя рабочий
интерфейс перенесён на пять постоянных страниц с прежними загрузчиками,
расчётами и отчётами. Навигация, тема и ширина панели не пересоздают данные.
